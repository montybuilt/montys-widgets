Abstraction manages complexity

  1. Focus: keep the information this user needs for this goal.
  2. Group: organize details under meaningful names.
  3. Function: organize an algorithm under one clear command name.
  4. Test: make sure the interface is both simple and complete.

The goal is not to hide everything. A useful abstraction hides unnecessary detail while preserving what the user needs.
